# 📱 Советская Квартира — Инструкция по сборке APK

## Что внутри проекта
- 🏠 3D советская квартира: диван, телевизор, стол, стулья, шкаф с книгами, холодильник, ковёр, окно
- 🕹️ Управление: виртуальный джойстик слева + свайп справа для камеры + кнопка JUMP
- ⚡ Оптимизировано под слабые устройства: GLES2 рендер, без теней, без HDR

---

## ШАГ 1 — Установи Godot на ноутбук (5 минут)

1. Открой браузер, зайди на: https://godotengine.org/download/archive/3.5.3-stable/
2. Скачай: **Godot_v3.5.3-stable_win64.exe.zip** (или win32 если 32-битная Windows)
3. Разархивируй — там будет один файл .exe
4. Запусти его (установка не нужна, просто .exe)

---

## ШАГ 2 — Открой проект

1. В Godot нажми **"Import"**
2. Найди папку `soviet_apartment` (которую ты распаковал из архива)
3. Выбери файл `project.godot`
4. Нажми **"Import & Edit"**
5. Нажми кнопку ▶️ (Play) чтобы проверить на ПК — должна открыться квартира

**Управление на ПК:** WASD — ходить, мышь — камера, Space — прыжок, Esc — освободить мышь

---

## ШАГ 3 — Создай аккаунт на GitHub (бесплатно)

1. Зайди на https://github.com
2. Нажми **"Sign up"**
3. Зарегистрируйся (email + пароль)

---

## ШАГ 4 — Загрузи проект на GitHub

### Способ А — через браузер (без Git, проще):

1. На GitHub нажми **"+"** → **"New repository"**
2. Название: `soviet-apartment`
3. Выбери **Public**
4. Нажми **"Create repository"**
5. Нажми **"uploading an existing file"**
6. Перетащи ВСЕ файлы из папки `soviet_apartment` (включая скрытую папку `.github`)

⚠️ **Важно:** папку `.github` нужно загрузить отдельно:
- Зайди в репозиторий → Create new file
- Напиши путь: `.github/workflows/build.yml`
- Скопируй содержимое файла `build.yml` из папки `.github/workflows/`

### Способ Б — через Git (если установлен):
```
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/ТВОЙ_НИК/soviet-apartment.git
git push -u origin main
```

---

## ШАГ 5 — Запусти сборку и скачай APK

1. Зайди в свой репозиторий на GitHub
2. Нажми вкладку **"Actions"**
3. Слева увидишь **"Build Android APK"**
4. Нажми **"Run workflow"** → **"Run workflow"**
5. Подожди 5-10 минут (зелёная галочка = готово)
6. Нажми на завершённый workflow
7. Внизу страницы найди **"Artifacts"** → **"soviet-apartment-apk"**
8. Скачай ZIP, внутри будет **soviet_apartment.apk**

---

## ШАГ 6 — Установи APK на телефон

1. Перекинь APK на телефон (через USB или мессенджер себе)
2. На телефоне зайди в **Настройки → Безопасность**
3. Включи **"Установка из неизвестных источников"**
4. Открой APK файл → Установить

---

## Управление в игре (телефон)

| Действие | Управление |
|---|---|
| Ходить | Джойстик слева |
| Поворот камеры | Свайп правой половиной экрана |
| Прыжок | Кнопка JUMP (справа внизу) |

---

## Если что-то не работает

**Godot не запускается** — скачай версию win32 вместо win64

**APK не устанавливается** — убедись что включено "Установка из неизвестных источников"

**GitHub Actions падает** — зайди в Actions → посмотри лог ошибки, напиши мне что там написано

**Квартира не отображается** — в Godot открой сцену Main.tscn и нажми Play
